Política de Privacidade

Esta política explica o tratamento de dados da integração de uso próprio com o canal Omnia Jesus.

Versão de 8 de outubro de 2026.

Responsável e finalidade

O aplicativo é operado pelo proprietário do canal Omnia Jesus. O contato para dúvidas, revogação e solicitações de remoção é generalvideopublisher@gmail.com. A integração serve para enviar vídeos preparados pelo proprietário, confirmar o destino e acompanhar o resultado dos envios.

Dados acessados e utilizados

  • Identificador do canal selecionado durante a autorização, para confirmar que o destino é o canal autorizado.
  • Arquivo de vídeo, miniatura, título, descrição, créditos e configurações de publicação preparados pelo proprietário e enviados ao YouTube.
  • Identificador do vídeo enviado e informações de processamento, visibilidade e metadados consultados pela API para confirmar o resultado.
  • Credenciais OAuth e tokens necessários para acessar a API, incluindo o token de renovação. O aplicativo não solicita nem armazena a senha da Conta do Google.

São solicitados somente os escopos youtube.upload e youtube.readonly. O aplicativo não solicita acesso ao Gmail, Google Drive, contatos ou dados de pagamento.

Armazenamento e proteção

As credenciais de produção são armazenadas como segredos criptografados do GitHub Actions. Durante a autorização inicial, arquivos locais temporários podem ser usados para concluir e validar a conexão. Credenciais não integram as páginas públicas, o código versionado ou os registros de execução.

Os arquivos de mídia podem permanecer temporariamente nos artefatos privados da execução, até a expiração configurada. O repositório privado mantém o histórico necessário para acompanhar os episódios e evitar envios duplicados, incluindo identificadores, metadados de publicação e hashes dos arquivos. Sessões retomáveis de upload são armazenadas de forma criptografada.

Serviços envolvidos e compartilhamento

O Google e o YouTube recebem a autorização e os arquivos e metadados necessários à publicação. O GitHub hospeda as execuções, os segredos e o acompanhamento privado da operação. O acesso no GitHub depende das permissões do repositório e das execuções.

O aplicativo não vende dados obtidos pela API nem os utiliza para publicidade ou treinamento de modelos de inteligência artificial. Roteiros e narração podem ser produzidos com serviços de IA; dados privados obtidos pela API do YouTube não são fornecidos a esses serviços para essa finalidade.

O uso de informações recebidas das APIs do Google observa a Google API Services User Data Policy, incluindo os requisitos de uso limitado.

Revogação e remoção

O proprietário pode revogar o acesso na página de conexões da Conta do Google. A revogação impede novas operações autorizadas, mas não exclui automaticamente vídeos já publicados ou o histórico privado existente.

Para solicitar a remoção de credenciais, arquivos ou dados de acompanhamento mantidos pelo aplicativo, entre em contato pelo e-mail acima. O operador executa a remoção nos locais de armazenamento envolvidos e informa eventuais etapas adicionais. A exclusão de um vídeo publicado deve ser feita pelo proprietário no YouTube; cancelar um episódio antes do envio impede seu upload, mas não exclui vídeos já enviados.

Este site

As páginas são estáticas: não têm formulários, login, cookies de aplicação, anúncios, rastreadores adicionados pelo aplicativo ou código de análise de visitantes. A hospedagem no GitHub Pages está sujeita à Política de Privacidade do GitHub. Google e YouTube possuem sua Política de Privacidade.

Alterações

Esta política será atualizada quando o funcionamento ou o tratamento de dados mudar. A versão vigente ficará nesta mesma página.
